# Priyanshu Lohar — Portfolio

A responsive React + Vite portfolio with a dark editorial visual system, custom CSS project illustrations, detailed project case-study panels, skills, experience and contact sections.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build for deployment

```bash
npm run build
npm run preview
```

The production site is generated in `dist/`.

## Deploy

- **Vercel:** Import this folder/repository. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.
- **Netlify:** Build command: `npm run build`. Publish directory: `dist`.
- **GitHub Pages:** Configure the Vite `base` option in `vite.config.js` if deploying under a repository subpath.

## Personalize before publishing

1. Verify project details and technologies against the actual implementations.
2. Add a downloadable resume file in `public/` and link it from the hero if desired.
3. Add a public portfolio / contact form endpoint only if you want form submissions; this version uses direct email and phone links.
4. Add real screenshots or product images if available. Current project visuals are CSS illustrations, not screenshots of the live products.
